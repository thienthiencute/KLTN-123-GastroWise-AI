### 2.2. Backend Legacy Spec Failures Analysis

When running the entire backend test suite (`npm test`), 8 boilerplate spec files generated by the NestJS CLI fail:
1. `src/auth/auth.service.spec.ts` & `src/auth/auth.controller.spec.ts`:
   - **Root Cause:** Path alias error: `Cannot find module 'src/users/users.service' from 'auth/auth.service.ts'`. Jest lacks `moduleNameMapper` mapping `'^src/(.*)$': '<rootDir>/$1'`.
2. `src/reviews/reviews.service.spec.ts`, `src/reviews/reviews.controller.spec.ts`:
   - **Root Cause:** Injected Mongoose models (`ReviewModel`, `RestaurantModel`) were not provided with mocks in the default generated test harness.
3. `src/restaurants/restaurants.controller.spec.ts`, `src/itineraries/itineraries.controller.spec.ts`, `src/users/users.controller.spec.ts`:
   - **Root Cause:** Unmocked services in default controller specs.
